# Yoga con Arjuna · web

Web de [yogaconarjuna.com](https://yogaconarjuna.com). Netlify la publica sola cada vez que hay un cambio en la rama `main`.

Las instrucciones para hacer cambios están en `CLAUDE.md`. La agenda se actualiza desde la hoja de Google «Agenda web Yoga con Arjuna».

## Quién puede publicar
El repositorio es público para que Netlify publique también los cambios de las colaboradoras (plan gratuito). Solo pueden modificarlo la propietaria y las personas invitadas.
